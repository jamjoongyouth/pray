# 교제 내용 — 질문지 + 답변 나눔 — 설계 문서

날짜: 2026-08-01
상태: 구현 완료 (패들릿 연결), 실사용 검증 남음

## 목적

사이트의 "교제내용 보러가기" 버튼이 회차별 질문지를 열고, 각자 자기 답을 올려 서로
나눌 수 있게 한다.

## 확정된 요구사항

- **공개 범위**: 올리는 즉시 서로 공개. 제출 전에도 남의 답을 볼 수 있다.
- **신원**: 선택. 이름을 쓸 수도, 익명으로 낼 수도 있다.
- **질문지 단위**: 날짜별 세트 3회(8/7, 8/14, 8/21), 회차마다 문항 3개.
- **로그인**: 요구하지 않는다. NFC로 여는 페이지라 로그인 요구는 이탈로 직결된다.
- **답변 형태**: 문항별로 칸을 나누지 않고 **자유 서술** 한 덩어리로 받는다.

## 선택한 접근: 패들릿 선반(Shelf) 하나

**패들릿 URL**: https://padlet.com/jamjoongyouth2/1-6w2qshnww4dpr426

```
사이트 [교제내용 보러가기 →]  (index.html, 새 탭)
   └→ 패들릿 (선반 포맷)
        [첫째 날 · 8/7]   [둘째 날 · 8/14]   [셋째 날 · 8/21]
         📌 질문 카드       📌 질문 카드        📌 질문 카드     ← 리더가 올리고 맨 위에 고정
         참가자 게시물…     참가자 게시물…      참가자 게시물…
```

- 게시물 **제목 칸이 곧 이름**이다. 실명·`익명`·공백 모두 본인 선택이므로 "신원은 선택"이
  별도 장치 없이 충족된다.
- 컬럼에는 설명란이 없다. 그래서 **질문은 각 컬럼 맨 위의 카드 하나**로 올리고 고정한다.
  질문을 바꾸는 것도 그 카드만 고치면 된다.

### 패들릿 설정

| 항목 | 값 | 이유 |
|---|---|---|
| 포맷 | 선반(Shelf) | 회차 3개가 컬럼으로 갈린다 |
| 프라이버시 | 비밀 — 링크 아는 사람만 | 검색엔진에 노출되지 않는다 |
| 방문자 권한 | 작성 가능 | 로그인 없이 올리되 남의 글은 못 고친다 |
| 게시물 승인 | 끔 | "올리는 즉시 공개"가 요구사항이다 |
| 댓글 | 켬 | 서로의 답에 한마디 붙일 수 있다 |
| 반응 | 켬 | 읽었다는 표시가 가볍게 남는다 |
| 새 게시물 위치 | 마지막 | 질문 카드가 맨 위에 남는다 |

패들릿 설명란 한 줄: `올린 글은 링크를 아는 모두에게 바로 보입니다.`

### 사이트 쪽

`index.html`의 `.fellowship` 섹션 링크 하나와 안내 문구뿐이다. JS 변경 없음.
버튼 클래스는 `.notion-btn` → `.fellowship-btn`으로 바꿨다(더 이상 노션이 아니다).
`css/style.css`가 바뀌었으므로 `index.html`의 캐시 버스터를 `?v=11`로 올렸다.

**iframe 임베드는 하지 않는다.** 모바일에서 페이지 스크롤과 패들릿 스크롤이 겹쳐
답답해진다. 새 탭으로 여는 편이 낫다.

## 왜 노션이 아닌가 (폐기한 접근)

처음에는 노션으로 설계해 실제로 만들었다. 노션 공개 페이지는 로그인 없이 글을 쓸 수
없어서(댓글·편집 모두 계정을 요구한다) **폼**이 유일한 통로였고, 구조가 "읽기용 공개
페이지 + 쓰기용 폼"으로 갈렸다. 데이터베이스 하나에 회차별 폼 뷰 3개와 갤러리 뷰 3개를
붙이고, 회차는 별도 속성 없이 "어떤 회차의 문항 칸이 채워졌는가"로 갈랐다.

동작은 했지만 두 가지가 걸렸다.

1. **답변판이 모여서 나누는 곳처럼 느껴지지 않는다.** 데이터베이스 뷰의 생김새를 그대로
   따르고, 사이트 톤과 이질적이며 모바일 첫 로딩이 느리다.
2. **쓰고 보는 흐름이 끊긴다.** 폼으로 나갔다가 제출하고 다시 페이지로 돌아와야 남의
   답이 보인다.

패들릿은 같은 화면에서 쓰고 본다. 덤으로 무료 플랜에서도 검색엔진 색인을 막을 수 있는데,
이건 노션 무료 플랜에서 못 하던 것이다(노션의 색인 차단은 유료 기능).

**대가**: 문항별로 칸을 나눠 받지 못하고 자유 서술이 된다. 답이 짧고 가벼워지는 대신
참여율은 올라갈 것으로 본다. 이 교환을 받아들이기로 했다.

만들어둔 노션 자산(`교제 나눔` DB, 폼 뷰 3개, 갤러리 뷰 3개, `기도 · 교제 내용` 페이지)은
지우지 않고 비공개로 남겨두었다. 사이트에서 링크하지 않을 뿐이다.

## 알려진 제약

- **본인이 나중에 수정·삭제할 수 없다.** 로그인 없이 올리므로 패들릿이 작성자를 특정하지
  못한다. 고칠 일이 생기면 리더에게 부탁해야 한다.
- **패들릿 무료 플랜의 개수 제한**이 있다. 선반형 하나만 쓰므로 걸릴 가능성은 낮지만,
  내년에 새로 만들려면 이걸 지우거나 보관해야 할 수 있다.
- **리더 계정 하나에 묶인다.** 패들릿 소유자만 남의 글을 지울 수 있다.

## 남은 검증

배포 후 실제 참가자 경로를 그대로 밟아 확인한다. 자동 테스트가 없는 구조라 이게 유일한
안전망이다.

- [ ] 폰에서 NFC(또는 배포 URL)로 사이트를 열고 "교제내용 보러가기"가 패들릿으로 가는가
- [ ] 패들릿 앱에 로그인하지 않은 상태(시크릿 브라우저)에서 게시물을 올릴 수 있는가
- [ ] 올린 글이 새로고침 없이 바로 벽에 뜨는가
- [ ] 제목을 비우고 올리면 어떻게 보이는가 (이름 자리가 어색하지 않은지)
- [ ] 컬럼 3개가 모바일에서 좌우로 넘겨지는가
- [ ] 질문 카드가 각 컬럼 맨 위에 남아 있는가 (새 글이 위로 올라오지 않는지)
